# Artifacts

Use esta pasta apenas para artefatos locais ou temporários:

- screenshots;
- vídeos;
- traces;
- logs;
- relatórios de execução;
- payloads sanitizados;
- resultados exportados.

Ela é ignorada pelo Git por padrão. Nunca salve aqui dados reais, secrets, tokens, cookies ou evidências que não estejam autorizadas.
